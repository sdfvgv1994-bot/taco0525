# 雲端看盤（電腦關機也能用手機看）

**網址：https://sdfvgv1994-bot.github.io/taco0525/monitor/**（全球看板右上角也有「📈 我的看盤」按鈕）

GitHub 的雲端機器每 15 分鐘幫你跑一次看盤：抓自選股報價、判斷策略訊號、照設定自動模擬交易，
再把結果做成網頁。和電腦上的看盤系統是**各自獨立**的兩份資料（雲端有自己的 100 萬模擬帳戶）。

## 修改設定（手機也可以）
1. 打開 [cloud_monitor/config.toml](https://github.com/sdfvgv1994-bot/taco0525/edit/main/cloud_monitor/config.toml)
   （網頁上的「⚙️ 修改設定」按鈕也會帶你過去）
2. 改自選股、策略、自動交易金額、停損、價格上下限
3. 按「Commit changes」存檔，15 分鐘內套用
4. 打錯格式也沒關係：網頁上會用黃色框寫出哪裡錯，並先沿用上一次正確的設定

## 運作方式
- **只在該市場的交易時間內**判斷訊號、自動交易（台股看台股時間、美股看美股時間）；休市時只更新報價
- 歷史資料用 Yahoo Finance（有今天約延遲 15 分鐘的價格）；台股另外試證交所即時報價，
  抓不到時價格旁邊標 `*`。中文股名從證交所 / 櫃買中心取得
- 帳戶、提醒紀錄、股名、資產走勢存在 GitHub 的 `monitor-data` 分支，每次執行後存回去
- 從自選股刪掉、但還有持股的股票會繼續追蹤，停損和賣出訊號照常運作
- 這是**公開網頁**：任何人都看得到自選股和模擬帳戶（模擬帳戶是虛擬的錢）
