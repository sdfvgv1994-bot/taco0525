# 雲端看盤（電腦關機也能用手機看）

**網址：https://sdfvgv1994-bot.github.io/taco0525/monitor/**（全球看板右上角也有「📈 我的看盤」按鈕）

GitHub 的雲端機器每 15 分鐘幫你跑一次看盤：抓自選股報價、判斷策略訊號、照設定自動模擬交易，
再把結果做成網頁。電腦上的看盤系統（桌面版、手機版）預設也用**這個帳戶**：電腦每分鐘看報價、提醒，
下單和改設定會寫回這裡（見 [stock_monitor/README](../stock_monitor/README.md) 的「雲端帳戶」）。

## 裝成手機 App
雲端看盤可以加到手機主畫面，之後像 App 一樣點圖示打開（全螢幕、沒有網址列；沒網路時顯示上一次的資料）。
- **iPhone**：用 Safari 打開網址 → 下方「分享」按鈕 → 「加入主畫面」
- **Android**：用 Chrome 打開網址 → 右上角「⋮」→「安裝應用程式」或「加到主畫面」
- 電腦（Chrome / Edge）：網址列右邊的「安裝」圖示
- App 打開的就是同一個網頁，內容、自選股編輯、手動下單、GitHub 權杖都一樣（權杖要在 App 裡再貼一次）

## 在網頁上加減自選股（最方便）
網頁上「✏️ 新增 / 刪除自選股、設定上下限與支撐線」：輸入代號按「加入」、按 ✕ 刪除、填上下限和支撐線，按「💾 儲存」，
大約 2～3 分鐘後雲端重新計算、網頁自動更新。
- 第一次儲存要在手機貼一組 GitHub 權杖（網頁上有步驟）：
  [建立權杖](https://github.com/settings/personal-access-tokens/new) → Repository access 只選 taco0525 →
  Contents 選「Read and write」→ Generate token
- 權杖只存在那支手機的瀏覽器裡，不會出現在網頁或倉庫上；手機遺失時到同一頁把權杖刪掉
- 儲存時其實就是幫你改 `config.toml`（保留檔案裡的說明文字），所以和下面的方法改的是同一個檔案

## 手動模擬下單
網頁上「🛒 手動模擬下單」：選股票、買進 / 賣出、股數（賣出可以勾「全部賣出」），按送出。
- 訂單會寫進 `cloud_monitor/orders.json`，雲端馬上重跑一次（約 1～3 分鐘），用那時候的價格成交
- 不在該市場的交易時間就先排隊，開盤後的第一次更新成交；5 天都沒成交就取消
- 一樣扣手續費、賣出台股扣證交稅；現金不夠、股數不夠、不在自選股裡會被拒絕，網頁上會寫原因
- 同一張訂單只會成交一次（處理紀錄存在 `monitor-data` 分支）；用的是和「編輯自選股」同一組 GitHub 權杖

## 配息配股（模擬帳戶也會領股利）
到了除權息日，模擬帳戶照持股拿股利，規則盡量照真的證券戶：
- **誰拿得到**：除權息日**前一天收盤**還持有的股數才算；除權息當天才買的沒有，當天賣掉的照樣有
- **台股現金股利**：除息日先記成「應收股利」，大約 30 天後入帳（實際發放日以公司公告為準），入帳時扣匯費 10 元
- **台股股票股利**：除權日直接加股數（每千股配 N 股），不足 1 股的畸零股按面額 10 元折成現金；
  總成本不變、股數變多，所以每股平均成本會變低
- **二代健保補充保費**：同一次股利（現金股利＋股票股利面額）達 2 萬元，整筆扣 2.11%
- **美股**：現金股利扣 30% 預扣稅，大約 7 天後入帳（金額是美元）
- 網頁上：帳戶多一格「應收股利」（算進總資產，除息當天股價下跌不會變成假虧損）、持股下面列「待入帳股利」、
  交易紀錄多「配股」「股利入帳」；手機推播「💰 除息」「💵 股利入帳」
- 資料：台股用台股總覽抓好的證交所／櫃買中心除權除息表，美股用 Yahoo；程式在 `dividends.py`

## 修改設定（手機也可以）
1. 打開 [cloud_monitor/config.toml](https://github.com/sdfvgv1994-bot/taco0525/edit/main/cloud_monitor/config.toml)
   （網頁上的「⚙️ 修改設定」按鈕也會帶你過去）
2. 改自選股、策略、自動交易金額、停損、價格上下限
3. 按「Commit changes」存檔，15 分鐘內套用
4. 打錯格式也沒關係：網頁上會用黃色框寫出第幾行、哪裡錯，並先沿用上一次正確的設定
   （手機打出的全形逗號、彎引號會自動當成半形；拼錯的設定名稱會提示正確的寫法）

## 手機推播（ntfy，免費）
有自動成交、買賣訊號、突破上下限或停損時，手機會收到一則通知（同一次更新的事件合併成一則），點通知會打開雲端看盤。

1. 手機安裝 **ntfy**（App Store / Google Play 搜尋「ntfy」）
2. 打開 App，按「+」訂閱，**頻道名稱**取一個別人猜不到的，例如 `taco-` 加一串亂碼（伺服器用預設的 ntfy.sh）
3. 到 GitHub 倉庫 **Settings → Secrets and variables → Actions → New repository secret**，
   Name 填 `NTFY_TOPIC`，Secret 填**同一個頻道名稱**
4. 下一次雲端更新（15 分鐘內）會先送一則「手機推播設定成功」，收到就完成了

- 頻道名稱等於密碼：知道名稱的人都收得到你的通知，所以只放在 GitHub Secrets，不寫進公開的設定檔
- 要推播哪些事情，在 `config.toml` 的 `[notify]` 設定；`enabled = false` 可以整個關掉

## 運作方式
- **只在該市場的交易時間內**判斷訊號、自動交易（台股看台股時間、美股看美股時間、日股看東京時間…）；
  休市時只更新報價。國定假日或資料還沒更新（還沒有今天的 K 棒）時也不判斷，不會把前一天的訊號再做一次
- 同一個提醒在同一根 K 棒只響一次（美股的一根 K 棒跨過台北午夜也不會重複）
- 歷史資料用 Yahoo Finance（有今天約延遲 15 分鐘的價格）；台股另外試證交所即時報價，
  抓不到時價格旁邊標 `*`。中文股名從證交所 / 櫃買中心取得
- 帳戶、提醒紀錄、股名、資產走勢存在 GitHub 的 `monitor-data` 分支，每次執行後存回去
- 從自選股刪掉、但還有持股的股票會繼續追蹤，停損和賣出訊號照常運作
- 某一檔這次抓不到報價時，持股先用上一次抓到的價格計算（價格旁邊標 ⚠）
- 雲端這次失敗（讀不到帳戶資料、程式出錯、存檔失敗）時，網頁會保留上一次的內容並標示失敗，不會打不開
- 均線、策略的天數最多 240 天（雲端抓一年的日 K）
- 移動停損：`[settings]` 的 `trail_stop_pct`，從買進後的最高價回落幾 % 就賣出（0 = 不使用）
- 支撐線：`[limits]` 裡寫 `"2317" = { support = [200, 190] }`，昨天收盤還在線上、今天跌破就提醒
- 看盤規則（訊號、停損、移動停損、支撐線、自動交易）和電腦上的看盤系統是**同一套程式**（`stock_monitor/engine.py`），
  只是帳戶和自選股各自獨立
- 這是**公開網頁**：任何人都看得到自選股和模擬帳戶（模擬帳戶是虛擬的錢）
