# 萬花筒畫板

```bash
python kaleidoscope/kaleidoscope.py
```

用滑鼠拖曳畫圖，筆畫會自動旋轉對稱（預設 8 向），顏色沿著筆畫變成彩虹。

| 按鍵 | 動作 |
| --- | --- |
| R | 自動產生隨機花樣 |
| U / Ctrl+Z | 撤銷上一筆 |
| C | 清空 |
| S | 儲存成 SVG（`kaleidoscope/drawings/`） |
| + / - | 增減對稱數（1～24） |
| M | 鏡像開關 |
| [ / ] | 筆畫粗細 |
| H | 顯示 / 隱藏說明 |
| Esc | 離開 |
