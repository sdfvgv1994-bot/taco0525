# 台股總覽

**網址：https://sdfvgv1994-bot.github.io/taco0525/tw/**

全部上市、上櫃股票和 ETF 的收盤行情一頁看完，電腦關機也能用手機看。
資料來自台灣證券交易所、櫃買中心的公開資料，不需要證券帳戶或證券商的 API。

## 網頁上有什麼
- **大盤**：加權指數、櫃買指數、成交金額、上漲／下跌／平盤家數、漲停跌停家數、三大法人買賣金額
- **排行**：漲幅、跌幅、成交值、外資／投信買賣超等排行
- **產業**：各產業的平均漲跌、漲跌家數、成交值，點進去看產業裡的個股
- **籌碼**：每檔的外資、投信、自營商買賣超（張）、融資融券餘額與增減
- **基本面**：本益比、殖利率、股價淨值比
- **全部**：所有股票的表格，可以搜尋、篩選、排序
- **點一檔股票**：近一年的日 K 線和成交量，以及最近 20 天的法人買賣超、融資融券

## 資料什麼時候更新
GitHub 的雲端機器每 15 分鐘跑一次（和全球看板同一個排程，`.github/workflows/board.yml`）。
各項資料在交易日大約這些時間公布，公布後的下一次更新就會出現：

| 資料 | 大約時間 |
| --- | --- |
| 收盤行情、指數、漲跌家數 | 下午 2 點後 |
| 本益比、殖利率、股價淨值比 | 下午 3 點後 |
| 三大法人 | 下午 3 點半後 |
| 融資融券 | 晚上 9 點後 |

還沒公布的資料會先顯示前一個交易日的，網頁上方會註明日期。
網頁上的「幾分鐘前更新」是**最後一次確認資料是最新的時間**：證交所、櫃買中心連不上時不會往前走，
網頁上方也會註明「行情還沒抓到 MM/DD 的」或「這次抓資料失敗，顯示的是之前抓到的資料」。
假日也會每 15 分鐘確認一次，超過 90 分鐘沒確認，網頁會提醒「雲端更新可能暫停了」（和全球看板一樣）。
這是**收盤後的資料**，不是盤中即時報價（盤中即時價格請看[全球看板](https://sdfvgv1994-bot.github.io/taco0525/)或看盤系統）。

## 第一次使用
- 第一次執行時快取是空的：最新一天的行情和籌碼第一次就會有，**歷史 K 線要分好幾次補齊**
  （每次只抓一點，避免被證交所封鎖），大約前幾個小時內會補到一年；
  補齊前網頁會顯示「歷史 K 線還在補齊中」
- 個股的法人、融資融券歷史（最近 20 天）在 K 線補齊後再補，再過大約半小時
- 颱風假、連假等休市日會自動發現並記下來，不需要手動設定（上市、上櫃都說那天沒有行情才算休市，
  不會因為一個網站暫時出錯就少了一個交易日）
- 上櫃的三大法人買賣「金額」目前沒有，只有上市的；上櫃個股的法人買賣超（張數）有

## 數字怎麼算
- **漲跌家數、漲停跌停家數**：只算股票，不含 ETF 和存託憑證（例如 9105 泰金寶-DR），和證交所公布的一致。
  漲停要收在「漲停價」（前一天收盤 × 1.1，依股價的升降單位往下取），所以南亞漲 9.58% 也可能是漲停，
  沒有漲跌幅限制的新股漲 12% 也不算。個股旁的「漲停」「跌停」標籤用同一個規則
  （存託憑證收在漲停價也會標，只是不算進家數）
- **除權、除息當天**：交易所不比較漲跌，網頁上的漲跌是「—」，也不算進漲跌家數
- **三大法人買賣超是 0**：那天沒有法人買賣（交易所的名單不列這些股票）；「—」才是沒有資料
- **外幣計價的 ETF**（代號最後是 K、M、S、C，例如 00636K）不收：價格、金額是美元或人民幣

## 自己在電腦上產生
```bash
python -m tw_market.build --out _site/tw              # 抓新資料＋產生網頁
python -m tw_market.build --out _site/tw --no-fetch   # 不連網，只用已經抓過的資料
python -m tw_market.build --out _site/tw --demo       # 示範資料（不連網）
```
抓過的資料存在 `.cache/tw/`，過去的日子不會重抓。和其他程式共用證交所的連線間隔（每次至少 3 秒），
被封鎖時會自動暫停，不會越抓封越久。

## 程式結構
- `contract.py`：網頁資料的格式定義（產生資料的程式、網頁、測試共用）
- `sources.py`：證交所、櫃買中心各個網址與解析
- `update.py`：決定這次要抓哪些資料（依重要性排隊、每個網站最多連 25 次、最多 4 分鐘）
- `store.py`：本機快取
- `build.py`：把快取組成網頁要的資料並輸出（先寫到暫存資料夾，成功才換掉舊的）
- `static/index.html`：網頁
